# ChatGPT Timeline

ChatGPT Timeline 是一个用于 ChatGPT Web 的 Chrome 扩展，主要用来更方便地按时间查找历史聊天，并补充 ChatGPT 原生界面没有显示的时间信息。

仓库链接：https://github.com/Roc-kit/ChatGPT-Timeline/tree/main

## 项目背景

Codex 很好用，但是 Plus 的额度根本不够用。后面主要使用 ChatGPT Web + DevSpace，遇到聊天记录查找、搜索不方便的问题，直接让 ChatGPT Web + DevSpace 开发了这个扩展。

开发人员：**ChatGPT Web + DevSpace**

## 功能

- 悬浮聊天目录：按创建时间查看、排序和打开历史聊天。
- 按项目筛选：可按普通聊天、不同项目或自定义 GPT 筛选；自定义 GPT 会显示实际名称，不直接暴露 `g-...` ID。
- Markdown 导出：可将聊天导出为 `.md` 文件。
- 原生侧边栏时间：可选显示聊天创建时间。
- 消息时间戳：可选给每条用户消息和 ChatGPT 回复显示发送时间。
- 设置入口：所有开关统一放在浏览器扩展 Popup 中，聊天目录面板只保留浏览、筛选和导出功能。
- 聊天目录关闭方式：默认点击目录外部会关闭，可在扩展弹窗中关闭此行为。
- 新标签页打开：可选择在后台新标签页打开聊天。
- 本地缓存：刷新页面后可先直接显示已有目录，再增量更新。

## 时间格式

聊天目录和原生侧边栏：

```text
2026-08-24 10:05 D1
```

`D1` 到 `D7` 对应星期一到星期日，其中 `D7` 为星期日。

单条消息时间戳：

```text
2026-08-24 09:46:21
```

## 权限

- `storage`：保存扩展设置、悬浮按钮位置和本地聊天目录缓存。
- `https://chatgpt.com/*`：在 ChatGPT 页面读取当前登录账户可见的聊天元数据并显示相关功能。

## 访问频率

- 页面内约每 30 秒检查一次是否有需要补充的 UI 元素；这一步不发网络请求。
- 聊天目录约每 5 分钟尝试一次后台增量同步；接口层有最短 60 秒同步间隔保护。
- 打开目录时优先读取本地缓存，只增量检查新数据，不会每次都重新读取全部历史聊天。
- 消息时间戳直接读取 ChatGPT 页面中已有的消息创建时间，不增加网络请求。
- 只有手动执行“完整刷新 / 重建缓存”时才会主动完整重建目录数据。

## 安装开发版

1. 打开 `chrome://extensions/`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择 ChatGPT Timeline 项目目录。
5. 刷新 ChatGPT 页面。
